## UART

- **U1 — Texas Instruments, Universal Asynchronous Receiver/Transmitter (UART) for KeyStone Devices User Guide, SPRUGP1, November 2010.** [Official PDF](https://www.ti.com/lit/ug/sprugp1/sprugp1.pdf). Read §2.1 clocking, §2.4/Fig. 2-3 framing, §2.5 operation, §3.6/Table 3-9 parity, and §3.8/Table 3-12 errors. This is a peripheral manual, not a universal UART standard. Link only: its final notice permits some reproduction of data books/data sheets but does not unambiguously grant this user guide's public redistribution. No device-specific errata qualification is claimed for a generic framing reference.
- **U2 — TI Precision Labs, UART protocol and error overview, 3 October 2022.** [Official training/transcript](https://www.ti.com/video/6313217959112). Framing and the sections discussing baud error accumulation, start synchronization, and sampling supplement U1. Link only; no redistribution permission established. No full video/media copy retained.
- **U3 — TI, Low Voltage Translation For SPI, UART, RGMII, JTAG Interfaces, SCEA065B, revised March 2021.** [Official PDF](https://www.ti.com/lit/an/scea065b/scea065b.pdf), §2.3, p. 6. Separates UART framing from RS-232/RS-485 electrical interfaces. Link only; no affirmative repository redistribution permission established.

## I2C

- **I1 — NXP, I2C-bus specification and user manual, UM10204 rev. 7.0, 1 October 2021.** [Official PDF](https://www.nxp.com/docs/en/user-guide/UM10204.pdf). §3.1.1–3.1.16 covers ordinary bidirectional transactions and recovery; §6.1, Tables 10–11 and Fig. 38 cover electrical/timing definitions; §7.1 covers pull-up sizing. Table 1 records revision changes. Pin these notes to rev. 7.0; no assertion that all future corrections are incorporated. Link only: copyright is reserved and no affirmative redistribution permission was found. Semiconductor-specific errata remain separate.

## USB

Publisher landing page: [USB-IF USB 2.0 specification](https://www.usb.org/document-library/usb-20-specification). Retrieved the official [3 June 2025 package](https://usb.org/sites/default/files/usb_20_20250603.zip); the `www.usb.org` download returned HTTP 403, while `usb.org` succeeded. Package date is **not** a new revision date for the base specification. All USB documents are link-only: no affirmative public repository redistribution permission was found. B1's front matter reserves copyright and does not grant an implied IP license.

- **B1 — Universal Serial Bus Specification, revision 2.0, 27 April 2000.** Package member `usb_20.pdf`. Promoters: Compaq, Hewlett-Packard, Intel, Lucent, Microsoft, NEC, Philips. Read chapter 5 transfer types/sizes; §7.1.5–7.1.12 line states, encoding, boundaries, reset and speed; §7.1.18.1 turnaround; chapter 8 packet/transaction/CRC rules; chapter 9 device state and requests. Printed p. 198 (PDF p. 226) defines CRC conventions.
- **B2 — USB 2.0 errata, 7 December 2000.** `errata-092800-1207001.pdf`. Reviewed chapter 5/7/8/9 corrections; the Fig. 8-31/8-32 caption correction explicitly includes full-/low-speed control and interrupt transactions. High-speed PING/test-mode corrections are not low-speed features. Hub-specific changes remain a hub implementer's separate obligation.
- **B3 — USB 2.0 errata, 28 May 2002.** `2002_05_28_errata.pdf`. Reviewed chapter 7/8/9 changes. A low-speed-only device designed to USB 2.0 also uses `bcdUSB=0x0200` and reports the appropriate request error for DEVICE_QUALIFIER; USB 2.0 does not mean high-speed-only. High-speed PING/NAK changes do not introduce PING at low speed.
- **B4 — Pull-up/pull-down resistors ECN.** `resistor_ecn.pdf`, undated document in the package (do not infer issue date from ZIP timestamps). Read summary and changes to §7.1.5.1/§7.1.5.2. Alters allowed resistor ranges while retaining D− attachment identification for low speed. Do not copy the base specification's old tolerances into a new electrical design without this ECN.
- **B5 — USB 2.0 Connect Timing Update ECN**, listed by USB-IF as 4 April 2013; `Connect Timing ECN.pdf`. Reviewed summary and attach/connect definitions: battery-powered device connection behavior is not fully described by the base document alone.
- **B6 — Suspend Current Limit Changes ECN**, listed as 9 April 2008; `Suspend Current ECN.pdf`. Reviewed summary/scope: changes suspend-current treatment. This reference does not select an electrical power budget.
- **B7 — USB 2.0 VBUS Max Limit ECN**, listed as 11 August 2014; `USB 2.0 ECN VBUS Max Limit.pdf`. Reviewed summary/scope: supersedes an electrical maximum; no VBUS limit is asserted by our logical model.
- **B8 — USB 2.0 DC Resistance ECN**, listed as 8 October 2021; `USB 2.0 DCR ECN.pdf`. Reviewed summary/scope: cable/path resistance and high-speed detection/test changes. It is not a replacement low-speed packet format.

The package also contains connector, OTG, inter-chip, LPM, high-speed isochronous, and other supplements. They were inventoried, not exhaustively qualified. Scope here is a conventional low-speed function. Electrical certification, hub/host implementation, a device class, or a broader USB implementation requires reviewing its complete applicable supplement set. No guide claims exhaustive USB compliance.

## Ethernet

- **E1 — IEEE Standard for Ethernet, IEEE Std 802.3-2012, published 28 December 2012.** [Official distribution information](https://www.ieee802.org/3/purchase/index.html), [GET program](https://standards.ieee.org/products-programs/ieee-get-program/), and [inspected mirror PDF](https://www.my-wire.de/schnittstellenbeschreibung/ethernet.pdf). Official Xplore automated access failed; the mirror contains the IEEE-authored document, not a tutorial. Read §3.2–3.4 frames/FCS, §4.2 and Table 4-2 MAC access/timing, §7.3.1.1 Manchester, and clause 14 10BASE-T, particularly §14.2.1.1, §14.2.1.7–14.2.1.8 and §14.3. Edition identity checked in front matter; byte identity against an official copy remains **unverified**. Link only: the copyright page requires prior written permission for reproduction. GET access is not redistribution permission.
- **E2 — Errata to IEEE Std 802.3-2012, 28 June 2013.** [Official PDF](https://standards.ieee.org/wp-content/uploads/import/documents/erratas/802.3-2012_errata.pdf); [retained original](ieee-802.3-2012-errata-20130628.pdf). Reviewed all six pages: corrections concern section-five material (clauses 59, 61, 72 and annexes 73A, 74A, 76A); they do not alter the clauses used for the basic 10 Mbit guide. This does not assert that no other correction exists. **Distribution terms, p. 1:** permits unchanged reproduction/distribution to maintain the underlying standard's utility/currency; forbids sale, licensing, and commercial distribution. Keep the file and notice intact, exclude it from commercial redistribution, and do not apply the repository's software license to it.
- **E3 — TI, DP83848-EP PHYTER Military Temperature Single Port 10/100 Mbps Ethernet Physical Layer Transceiver, SLLSEC6E, revised June 2019.** [Official PDF](https://www.ti.com/lit/ds/symlink/dp83848-ep.pdf). §5.3.1 Auto-Negotiation; §5.5.1.3 10BASE-T transceiver; §4.7.21–4.7.22 pulse timing. Supplemental illustration of PHY responsibilities, not a selected part or substitute for IEEE requirements. Link only: downloaded file's final notice restricts other reproduction/display; no repository redistribution grant established.

## Retained material and limits

Only E2 is retained as a source PDF. Other inspected originals stayed in temporary research storage; this repository has their citations, metadata, and hashes, not copies or extracted full texts. No documents were purchased, no account terms accepted, and no mirror was used to claim official byte authentication. Recheck revision/errata and source availability when expanding a guide or making hardware claims.
