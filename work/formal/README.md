# Formal properties

Properties named in v0.3 section 7, and repeated as the G3 check in [knowledgebase/phases.md](../../knowledgebase/phases.md):

- program-counter bounds
- `WAIT N` is exact
- a single pin owner
- a FIFO that would drop an entry sets the flag instead
- reservoir saturation bounds
- bounded fading memory

Each filed result is a proof or a counterexample. No properties are encoded here yet.
