# Firmware

Programs and weight files for the core and symbol layer. Tier 1 delivers UART, SPI, and I2C as degenerate-configuration weight files plus firmware; fast responses are reflex-table entries, not pin ops (the ISA has none). Protocol behaviour that the specs do not fix stays in the placeholders under `knowledgebase/placeholders/protocols/` until a source is filed.

No programs are in this directory yet.
